---
title: Уведомления
description: Используйте элементы управления уведомлениями и режимом «не беспокоить».
---
`argvus-notifications` предоставляет команду уведомления и конфигурацию Dunst. Его публичный интерфейс включает:

```sh
argvus notifications status
argvus notifications dnd status
argvus notifications dnd on
argvus notifications dnd off
argvus notifications dnd toggle
```
Служба уведомлений запускается `argvus-session`; Панель управления отображает состояние уведомлений и элементы управления. Пока активен режим "Не беспокоить", Dunst сохраняет входящие уведомления для последующего просмотра, а ARGVUS закрывает любые всплывающие окна, уже находящиеся на экране. Панель управления скрывает список уведомлений до тех пор, пока режим "Не беспокоить" не будет выключен. Изменения темы откладывают перезагрузку Dunst до выключения режима "Не беспокоить", поэтому смена темы не отключает его.
